# Task_3 — UI-тесты Stellar Burgers

17 сценариев в Google Chrome и Mozilla Firefox — 34 запуска.

Проверяются:
- восстановление пароля;
- личный кабинет и выход из аккаунта;
- конструктор, детали и счётчик ингредиентов, оформление заказа;
- детали заказов, история, общие счётчики и раздел «В работе».

Используется Page Object Model. Страницы находятся в `pages`,
локаторы — в `locators`, тесты — в `tests`.

Для каждого запуска создаётся отдельная браузерная сессия.
Тестовые пользователи создаются через API и удаляются после тестов.

## Подготовка

Требуются Python, установленные Chrome и Firefox.
Для формирования HTML-отчёта нужен Allure CLI.

```powershell
python -m venv venv
.\venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Запуск

```powershell
.\venv\Scripts\python.exe -m pytest tests -v --alluredir=allure-results --clean-alluredir
```

## Allure

```powershell
allure generate allure-results -o allure-report --clean
allure open allure-report
```

## Особенности и ограничения

- В Chrome используется ActionChains для перетаскивания.
  В Firefox используются синтетические HTML5 drag-and-drop события: они проверяют обработчики приложения, но не нативный жест мыши.
- Общие счётчики проверяются на увеличение, поскольку стенд используется другими пользователями. Дополнительно проверяется наличие нашего заказа.
- Для фиксации кратковременного появления номера в разделе «В работе» используется MutationObserver в отдельной вкладке.
- При ожидании номера заказа исключается временное значение 9999. Настоящий заказ с номером 9999 также будет отклонён этой проверкой.
